#Project requirements

#### Data structure:

- Category:
    - Name
    - Description
- Article:
    - Image
    - Title
    - Description
    - Text
    - Category (one or more)
    - View count

#### Required pages:

- Home page:
    - Display each category containing articles and show the 3 most recent posts (by publication date).
    - Display an “All articles” button for each category.

- Category page:
    - Display the title, description, and list of articles.
    - Implement article sorting (by view count, by publication date).
    - Implement pagination.

- Article page:
    - Display all article information.
    - Display a section with 3 related articles.


#### Additional functionality:
- Implement functionality for seeding categories and articles.
